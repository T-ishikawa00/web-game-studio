## 設計判断（実装前）

短い3作戦×6区画・3ボス・2系統4最終形態を維持。数字は市場最適値ではない。Aは射出位置、Bは敵優先度と射線、Cは資源を保持する時間を問い直す。Canvas/WebAudio/Vite継承。永久能力値稼ぎ、無限wave、engine移行不採用。

Nova Drift開発者の有限終点・mod組合せ調整負担の振返り、Gun Knightの強構成への収束を指摘する個別投稿から、選択数の増加より行動差を優先する（一次URLと採取条件はIndependent Validation参照）。支援敵を無敵鍵にせず修理役とし、無視して火力で押すことも可能にする。新ボスは常時攻撃可能、側面と突進後の冷却口が有利。装甲運搬機案をこの具体仕様へ調整する。

## 敵・ボス・進化

通常敵の制作上限6枠：basic近距離圧、heavy固定資源庫（basicの重装variation）、shield正面遮断、charger移動誘導、射線砲予告直線、支援機修理。heavyを新規の独立役割として水増ししない。eliteは通常枠外の既存強敵。

|形態|攻撃/防御/回収|弱点と判断|
|---|---|---|
|SWARM CYCLONE（既存）|広角一斉射出・近接盾開放|遠方単体に散る、近くで撃つ価値|
|SWARM SATELLITE（新）|射出時4片を防御予約、被害1回で1片が2秒離脱、残りを射出|攻撃量を防御へ配分、予約を使い切れば守れない。離脱片は再回収可|
|LANCE RETURN（既存）|細い貫通・自動回収|位置合わせが必要、密集射線に価値|
|LANCE FOUNDRY（新）|最大3片を束ねた単体重弾、正面装甲への減衰を緩和|複数貫通を失い、外せば手動回収。束の数より狙う相手|

Batch A module 4種：FIELD（保持時吸引範囲+100）、BRAKE（射出反動を抑え再照準）、SALVAGE DRIVE（敵装甲回収で短い移動加速）、SHOCK（射出時近距離押し出し、ボス無効）。2つ選択、重複候補を除外。自動回収はRETURN専用価値として残し重複moduleを作らない。
残り最大8枠は保留。全量設計では共通6＋系統各3を上限に、実験で独立した行動差を示したものだけ追加。現段階で12個の名前を埋めることはしない。候補案：方向保持補助/送電支援（共通）、周回距離/近接崩し/分散角（SWARM）、貫通後減衰/回収弧/狙撃窓（LANCE）。同じ強化の別名、常時上位互換、不可欠な希少抽選は棄却。

|module/候補|相乗と選ぶ行動|重複・棄却条件|
|---|---|---|
|FIELD / 実装|SWARMは広い回収、FOUNDRYは外した重弾を拾う位置が増える|RETURN自動回収とは異なり未発射の遠い金属にも作用|
|BRAKE / 実装|細いLANCE射線とボス側面の位置を維持|反動が退避を助ける状況では一概に上位ではない|
|DRIVE / 実装|撃破装甲を拾って次の敵の背後へ移る、衛星の防御片を再回収|持続永久加速や通常空弾で無限更新にしない|
|SHOCK / 実装|近距離の通常敵を押し返し衛星の守備位置を作る|CYCLONEの盾開放は追加せず、push加算に限定。ボス無効を表示|
|方向保持補助 / 共通候補|移動時の手動照準方向を安定させtouchを補助|自動照準と同義ならmoduleにせず入力設定へ移す|
|送電支援 / 共通候補|戦闘中に設備へ射出する価値を増やす|戦闘後自動送電を遅らせて価値を捏造しない|
|周回距離 / SWARM候補|接近して金属を構える位置を変更|衛星の単純容量増加と同義なら棄却|
|近接崩し / SWARM候補|保持→射出の間に盾の横を取る|CYCLONE完全重複なら候補に出さない|
|分散角 / SWARM候補|密集広角と狙った方向の集中を交換|新ボタン不要、FOUNDRYの単体重弾を代替しない|
|貫通後減衰 / LANCE候補|縦列を狙う旧RETURNの価値|単体FOUNDRYには提示しない|
|回収弧 / LANCE候補|撃った後に横へ動き回収路を変える|RETURNの単純自動回収追加にはしない|
|狙撃窓 / LANCE候補|短く停止してから射出する位置取り|溜め待機を強制する最適解なら棄却|

後半8案は未採用の検証バックログ。互換表を満たさない案を削り、4〜12の有効poolで完成してよい。各回は保有重複と無効な系統候補を除外し、最低2有効案を保証。今回初回4択はReviewで比較を選びやすくするため、以後は未選択3択。

## 進行・保存契約（Batch Bで実装）

初回A→B→C→Normal End。Aの早い地点で両系統、Aクリアで両新final解放。B/Cの失敗でAへ戻さない。Normal End後にChallenge（敵予告/組合せ変更、HP水増しだけにしない）と記録更新。4選択は1/2/3/5後、Batch Aのみ代表区間へ直接入る2つの初期選択＋区画後2選択。

namespace `tinlumo.game004.magnet.full.v1`（予約、今回書込みなし）。profileはschemaVersion/contentVersion/settings{locale,muted,reducedMotion}/unlockedMissionIds/finalIds/records{missionId,difficulty,form,time,clear}。runは別key `.run`、schemaVersion/contentVersion/missionId/encounterId/difficulty/build/final/modules/HP/maxHP/carriedScrap{kind,salvaged}/seed/elapsed/confirmedChoices。

区画開始時の確定snapshotのみ。粒子・敵途中座標・音声は保存しない。次区画移行時は検証済みenvelope全体を単一setItemし成功時だけ保存表示。profileとrunのcommitIdを突合し、profile未確定runを採用しない。死亡時runのみ削除しprofile維持。削除失敗時は明示して再開候補を無効扱い、次sessionで矛盾確認。破損/未知版/旧版は原文を上書きせずread-only復旧案内、明示resetで該当004のみ消去。容量/保存拒否時はメモリで続行可だが保存成功と表示しない。既存3作品keyへアクセスしない。完全瞬間復元・同期は約束しない。
