# Game005 Expansion Slice R1 — 暮らしの入り江

2026-09-23。HumanはProgression A「住み継ぐ島」を採用し、Accepted MVP直後の一段階だけの隔離実装を許可した。これはFull Game Productionの開始、Baselineの変更、公開の許可ではない。

## 体験と判断

目標は「橋の向こうを、暮らしの入り江にする」。橋だけの時点では住民が対岸の入口へ行って戻る。入口の小道を整えた後、広場と回遊路のどちらへ先に投資するか、広場を海際と木陰のどちらへ置くかをHumanが決める。

|状態|3D空間の変化|自動住民の変化|
|---|---|---|
|Before：橋完成|既存の対岸・海岸・植生をそのまま残す|橋の端へ歩いて戻る。着席場所はない|
|入口を整える|橋の板道と地面を接続。踏み場、植栽、灯り|余剰時間に新しい入口まで歩く|
|広場先行|選んだ場所へ短い枝道、共有縁台、鉢植え、小物|一人が広場へ向かい、座り、元の村へ戻る。回遊路完成前も用途がある|
|回遊路先行|海辺と木陰を巡る道、二つの立ち寄り地点|一人が歩き、海／木陰を眺め、戻る。まだ座れない|
|Lived-in：両方完成|枝道と回遊路がつながり、歩く場所と休む場所が分かれる|最大3人が余剰時間に回遊・立ち寄り・着席。仕事が発生すれば自動復帰|

|判断|海際の広場|木陰の広場|
|---|---|---|
|主な景観|水面を向く縁台、木のデッキ、低い植栽|既存樹木の脇、透ける格子の屋根、縁台、小さな卓|
|完成後の余剰時間の順|広場で着席 → 東の眺め → 北の木陰 → 村|北の木陰 → 広場で着席 → 東の眺め → 村|
|接続|橋から海側へ曲がる。木陰への未建設ショートカットを使わない|橋から木陰への枝道ができ、北側の滞在を中心に巡る|
|空いた場所の見え方|木陰の空間が残り、木々の間へ育てる余地が見える|海際が開けたまま残り、水面に向けて育てる余地が見える|

海際／木陰の両配置、広場／回遊路の両順序、計4通りが成立する。配置の違いに幸福度や生産倍率は付けない。完成後は既存Galleryから無料で広場を移せる。建設／資材予約／出荷中の移設は無効。住民は移設前の実位置から歩いて戻り、新しい場所を使う。

「次に育てたくなる」は設計意図であり、実装や技術QAで実証した保持率ではない。港・高台・地区3〜5・次の建設候補は追加していない。

## 増やしたものと増やしていないもの

|項目|このSlice|
|---|---|
|資源|木材／資金の2種類を維持。新通貨・交易・offline収益なし|
|住民|橋完成時の3人を維持。新住民・個別割当・人口管理なし|
|建設候補|入口の小道、暮らしの広場、回遊路の3件。既存5施設もGalleryから到達可能|
|費用|入口12木材／8資金、広場12／8、回遊路8／8。合計32木材／24資金。採集・出荷の既存速度／単価を維持|
|工事|各24 worker-seconds、最大2人作業。移動を含む実時間は実測をReviewに記録。長時間タイマーや納品回数ノルマなし|
|UI|Accepted Gold CSSをそのまま使用。既存カード、費用、状態、配置CTAに統合。橋完成後に入り江を見るカメラ操作を追加|
|目標|元の3目標に入口／人が集まる場所の短い2段階。地区レベル、幸福度、人口等の常設指標なし|
|景観|橋と道の接続、二つの広場構成、回遊路、縁台、鉢植え、灯り、小物。既存の島・海岸・木々を維持|
|動作|余剰時間の散歩、立ち止まり、着席。着席地点を通り抜け道に使わず、空いている席を自動選択|

余剰時間の行動には数秒の立ち寄りがあるが、進行を解放するための待機ではない。完成後すぐ次の建設へ進める。Reviewの観察時間は操作必須時間と区別する。

## 自動作業・保存の境界

作業割当が余剰時間行動より先に評価される。新しい工事／明示出荷／備蓄補充が必要なら、住民は座席・散歩の予約を解除して実位置から仕事へ移る。運搬中の荷物と到着払いを維持し、仕事が終わって資源が満ちれば再び入り江を使う。住民の選択画面はない。

候補は `game005-island/expansion-r1/` にコピーして隔離。保存は `tinlumo:game005:island:expansion:r1`、envelope/schema version 3。Accepted MVPのversion 2保存は読み書き・移行しない。通常試遊は候補内で元のMVPから始まり、橋の完成後に本Sliceへ連続する。完成状態へのショートカットや状態注入を通常製品に設けない。

入口・広場配置・回遊路・資材予約・工事進捗・作業／余剰時間の移動途中を保存。建設順の独立した数値や管理項目は持たず、「先に完成した施設＋現在の建設」を保存して順序を保持する。両施設完成後の行動は現在の配置と接続から決まる。破損原データ保全、容量／拒否の一時モード、複数タブ競合、確認付きresetを継承。offline経過時間による加算はない。

## Reviewと残るHuman Gate

[一括Review](../../game005-island/expansion-r1/review/index.html)、[QA・実測・制限](../../game005-island/expansion-r1/review/REPORT.md)、[通常試遊](http://127.0.0.1:4395/)。Route A＝広場先行／海際、Route B＝回遊路先行／木陰。両方をfresh browserから通常入力だけで完走し、全編の等速動画と同じ入り江カメラでのBefore／建設中／完成直後／利用中／最終景観を残す。動画は無音の画面記録。ゲーム内の既存音は維持しており、実聴の品質を録画からPASSにしない。

Humanが実際に試遊して判断する項目は、(1)装飾追加でなく発展に感じるか、(2)判断が楽しいか、(3)住民の利用が暮らしに見えるか、(4)配置差が意味を持つか、(5)MVPより面倒でないか、(6)さらに育てたいか、(7)Accepted Craft／UI品質を維持するか。独立レビューは重大な不成立を検出する工程であり、Human Acceptanceの代替ではない。

Physical iPhone／Safariは **NOT TESTED**。現時点の必須Gateにはしない。長期再訪、実機の発熱／電池、Safari、外部初見、配置の好み、10時間構造、Full Gameの費用／コンテンツ量はUNKNOWN。Gate通過まで港・高台・次地区・Full Gameへ自動拡張しない。

stage／commit／push／deploy／public registry／Cloudflare／AdSense／App Store／外部設定／LAN操作は未許可。主担当と独立read-only reviewerの実利用モデルは `gpt-6-astra`、追加writerなし。最終実測と判定はReview Reportを正本とする。
