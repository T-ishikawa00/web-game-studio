# Studio Craft Pipeline — validated learning from Tiny Delivery

Derived from Human's formal selection of B in Tiny Delivery BGM Pilot 01. [Production Playbook R2](WEB_GAME_STUDIO_PRODUCTION_PLAYBOOK_R2.md) remains the adopted operating standard, preserved unchanged. [Craft Baseline R2](../games/CRAFT_BASELINE_R2.md) records the accepted result; this document records reusable process, not a universal sound recipe.

## Validated process

**Visual → Interaction → Motion → SFX → BGM candidate → Mix → Human comparison → Freeze**

1. Preserve the accepted visual and interaction baseline before adding craft layers.
2. Add Motion and SFX where they clarify input, response and outcome. Preserve silence and immediate input.
3. BGM is optional. Always keep and compare a no-BGM baseline; no music is a valid outcome.
4. Compare music in the actual game at matched state, input schedule, viewport, SFX and gain. Keep standalone and gameplay listening evidence.
5. If a liked song feels wrong, separate rhythm, phrase spacing, tempo, transitions, loop join and restart/resume entry before considering a rewrite. Do not assume BPM is the cause.
6. Prefer the smallest change that removes the problem while retaining Human-valued identity. Tiny B shifted existing onsets at the same tempo; no extra instruments, complexity or volume were needed.
7. When Human sufficiently likes the candidates and remaining differences are small, accept the explicit selection and stop endless polish. Tiny B was only slightly preferred; this was sufficient for PASS and Freeze.
8. Keep technical measurements separate from listening acceptance. A zero endpoint jump, passing lifecycle suite or unclipped graph recording cannot establish concentration, naturalness or enjoyment.

## Freeze gate

Record the exact accepted version, source/PCM/runtime identity, mix, comparison evidence, Human scope and exclusions. Keep rejected/comparison variants as evidence, not active alternatives. Run checks appropriate to the final difference; reuse valid long playback and media evidence when byte identity is proven. New tuning requires a new Human request.

Each later title needs its own event selection, silence, musical direction and Human comparison. Do not copy Tiny's concrete song, timbre, 80 BPM, SFX or Motion mechanically. This learning authorizes no other-game implementation, public release, legal/ads acceptance, purchase, API or contract.
