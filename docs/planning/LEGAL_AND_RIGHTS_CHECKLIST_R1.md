# Legal and Rights Checklist R1

状態: 実務の確認項目 / 法的助言・適法性保証ではない。公開用Privacy/TermsはDRAFT / NOT LEGALLY REVIEWED。運営者、住所、メール、対象地域、準拠法を捏造しない。

## 原則
AI-generated does not mean legally risk-free. アイデアや一般的な操作の着想と、保護される具体的表現を区別する。他作品のアート、UI、正確な面構成、キャラクター、音楽、ブランド、ソースコード、文章/物語表現をコピーしない。似て見える場合は独自実装というだけで済ませず、表現をレビューする。

本書は権利処理の運用計画。地域ごとの法的結論は未検証であり、判断が必要な事例は専門家に確認する。

## 各作品の権利台帳
| 項目 | 必要な記録/証拠 |
|---|---|
| コードの来歴 | 作者、作成/取得日、元リポジトリ、改変、ライセンス |
| AI支援開発 | 使用ツール、作成部分、Humanレビュー、入力素材の利用権、利用規約の確認記録 |
| アート | 作成者/生成ツール、入力参照、取得元、商用/改変/再配布の範囲 |
| 音楽 / 効果音 | それぞれ作者/配布元/ライセンス/証拠、ゲーム内・動画・配信での利用範囲 |
| フォント | 配布/埋込/webfont/商用利用の条件、必要な著作権表示 |
| 第三者素材 | 元URLと取得日、原本ライセンス、購入/許諾証拠、クレジット |
| OSS依存 | lockfile、package別licenseとNOTICE、配布義務、更新履歴 |
| 商用利用 | 明示的な許諾範囲、禁止用途/地域/期間 |
| 動画/配信 | 音楽を含む録画・配信・収益化の可否、Content IDの懸念 |
| 名前/商標 | 候補名、対象国/区分、調査日/方法/結果、専門確認の要否 |
| 類似/独自性 | 比較対象、画面/レベル/演出/キャラの相違、レビュー担当/日付 |
| リリース | version、変更点、未解決項目、証拠へのローカル参照/リンク |

各項目は「未確認 / 確認済み（証拠あり） / 不適合 / 対象外（理由あり）」で管理する。リンクがあるだけでは利用許可と判定しない。実装完了から権利クリアを推定しない。

## 公開前の別途判断
運営者情報、Privacy/Terms、対象年齢・未成年者、広告の同意/データ処理、地域ごとの必要表示、cookie/localStorageの扱い、サポート窓口、削除/問い合わせ手順、配信契約の独占条件。記録が足りない素材、近似作品、商標、地域を跨ぐ配信、広告データ処理の不明点は専門レビューへ回す。
