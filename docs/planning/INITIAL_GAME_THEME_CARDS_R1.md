# Initial Game Theme Cards R1

3件とも構想段階・未制作。仮題であり商標確認前。内部Connection Labと別物。Humanが1件を選ぶまで実ゲームの制作は開始しない。選択後も導入/中後半のHuman試遊を経てから全制作に進む。

## A — Larva Evolution Lab / 幼体進化ラボ
- **核:** 小さな生物を動かし、資源を集め、進化を選ぶ。新能力で以前届かなかった足場/通路へ進む。失敗は近くから即再開。
- **視覚的な見どころ:** 体の形と動きが変わり、同じ場所で以前できなかった行動が可能になる瞬間。
- **動画適性:** 「届かない→変身→届く」が言葉を多用せず伝わる。
- **見た後も遊ぶ理由:** 自分で別の能力を選び、ルートと操作感を試したい。分岐の深さはまだ仮説。
- **導入試作:** 小さな2Dエリア、資源1種、2つの能力選択（例:登る/跳ぶ）、能力に対応する障害、戻って選び直せる。巨大3D、数十進化、オンライン、長時間待機なし。
- **中後半の確認:** 同じ能力の数値強化ではなく、行動が変わる一段階の追加進化と、それを使う代表的な障害を先に試す。
- **最大の技術リスク:** タッチ移動と当たり判定、能力切替後のカメラ/地形/操作の整合。2Dの小さな範囲から検証。
- **独自性/権利チェック:** 既存キャラクターの輪郭・進化系統・色/演出・世界観を再現しない。独自の生物造形と地形を設計。タイトル調査未実施。
- **Humanへの質問:** 進化前後で「できることが変わった」と感じたか。次の能力を試したいか。集める部分は待ち時間になっていないか。操作は直感的か。

## B — Light & Mechanism Workshop / 光と仕掛けの工房
- **核:** 部品を置く/回す/つなぎ、光を到達点へ導く。配置→点灯確認→修正を短く回す。
- **視覚的な見どころ:** 暗い盤面に光の経路が走り、最後の装置が動き出す。信号の流れが読める。
- **動画適性:** 「ここで止まる→一部品を変える→つながる」の前後差が明快。
- **見た後も遊ぶ理由:** 自分の別解を試し、未見の条件を解く。全解答を見せるだけのクリップにはしない。
- **導入試作:** 小さなグリッド、光源/到達点、回転できる反射部品と遮断物。少数の導入状況で操作と楽しさを検証し、総面数は決めない。
- **中後半の確認:** 分岐や開閉スイッチの組合せを使う代表的な課題。導入版の楽しさを確認した後に試す。
- **最大の技術リスク:** ループする光路や分岐の停止性、見やすい光線、小画面での部品操作。有限の状態探索と接続の可視化で検証。
- **独自性/権利チェック:** 他作品の盤面、部品外観、配色/UI、到達時演出をコピーしない。光路の一般的着想と具体的レベル表現を分ける。
- **Humanへの質問:** 何が原因で届かないか見て分かったか。正解が気持ちよいか。試し直しが速いか。説明なしで触れたか。

## C — One-Move Chain Challenge / ワンムーブ・チェイン
- **核:** 一つの配置/起動を選ぶと、連鎖が盤面を解決する。予測→起動→観察→即再試行。
- **視覚的な見どころ:** 最初の小さな一手から、画面全体へ規則的な変化が広がる。
- **動画適性:** 数秒の予想と連鎖の結末で短尺が成立しやすい。実際の動画効果は未検証。
- **見た後も遊ぶ理由:** 「自分ならここから」の予測を試す。別の初手と新しい配置に価値を置く。
- **導入試作:** 固定の小盤面、単一トリガー、1〜2種の連鎖規則、再生/即reset。スコア課金、オンラインランキング、大規模物理シミュレーションなし。
- **中後半の確認:** 同時分岐/時間差のルールが組み合わさる代表盤面。多面量産前に解く面白さと読める演出を確認。
- **最大の技術リスク:** 決定的な伝播順序と演出の同期。連鎖が長すぎて観察待ちになる、結果が読めず偶然に感じるリスク。
- **独自性/権利チェック:** 既存の連鎖ゲームのレベル、オブジェクト、サウンド、UI/演出を複製しない。独自の規則と視覚表現を明文化。
- **Humanへの質問:** 結末を予測したくなったか。外れた理由が分かったか。すぐ別の一手を試したか。運任せに感じないか。

## 初手の提案（未決定）
Bは小さな範囲でルールの可読性と成功の気持ちよさを検証しやすいという制作上の判断。Aは進化の変化、Cは短い再挑戦を優先したい場合に適する。どれが市場で強いかは未検証。最初のtutorial prototypeはHumanの選択で決める。
