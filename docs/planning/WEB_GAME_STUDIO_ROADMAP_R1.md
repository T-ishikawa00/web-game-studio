# Web Game Studio Roadmap R1

日付: 2026-09-13 / Authority: `../../START_HERE_CODEX_WEB_GAME_STUDIO.md`（実際の参照はリポジトリルート） / 状態: ローカル基盤、Human未受入。

## 事業仮説と対象
AI/Codex支援で、見て理解でき、動画視聴後も試したくなるブラウザゲームを作る。初期Portalは自社開発作品のみ。日本語・英語を同時に扱う。中国本土向け展開、外部開発者マーケット、アカウント、クラウドセーブは初期範囲外。

ゲームは無料・ゲーム内購入なし。承認後の広告収益を検討する。集客・継続率・採算は仮説であり、まだ計測結果はない。Cloudflareはインフラの第一候補で、採用・契約・実料金は未確定。

## 段階と通過条件
| 段階 | 成果物 | 次へ進む条件 |
|---|---|---|
| R1 基盤（今回） | 日英Portal、registry、内部fixture、保存・mock広告・イベント、計画文書、QA | 技術QA合格、HumanがPortalを確認。外部公開なし |
| 最初のテーマ決定 | A/B/CのうちHumanが最初の1候補を選ぶ | 選択を記録。候補カードはまだゲームではない |
| A–C 試作 | コアループ、導入試作、代表的な中後半試作 | BとCでHuman試遊。弱い核は修正または中止 |
| D–F 制作 | 最終体験から逆算した内容、必要最小限の制作、受入 | Humanによる最終プレイと受入。権利・品質確認 |
| 1〜3作時点の検証 | 外部/Humanの試遊、理解度・再挑戦・視聴後のプレイ意向 | 外部公開や招待送信は別途Human承認。10作まで隠さない |
| 初期公開判断 | 約10本の良質な自社開発ゲームを目安 | 本数だけで判断しない。権利・性能・サポート・法務・配信条件・コストを確認 |
| 運用改善 | 入口作品1〜2本、日英映像、回遊・再訪検証 | 実測に基づき追加制作・配信・広告を判断 |

100本は初期公開要件ではない。将来100以上の試作/タイトルが可能かは運用実績による。約5パズル/約3進化/約2短時間チャレンジは仮配分で、ノルマではない。

## 今回の完了と未完了を分ける
技術的bootstrap完了は公開許可・製品受入・広告承認ではない。内部fixtureはGame 001でも発売本数でもない。現在の公開ゲームは0本。テーマ選択前に実ゲームのフル制作を始めない。

## 変更・外部操作
変更先は本リポジトリのみ。別プロジェクトのkarakuri-repair等は参照素材扱いであっても変更禁止。リモート作成、push、deploy、ドメイン購入、申請、実広告、契約、外部送信は今回禁止。後の実行には具体的な対象とHumanの承認が必要。

## 未確定
正式なスタジオ名、公開日、制作速度、10作の内訳、対象年齢/地域、実プレイ継続率、制作コスト、収益、広告パートナー、ドメイン。数値目標や合格ラインは実測後に定義し、現時点の事実として捏造しない。
