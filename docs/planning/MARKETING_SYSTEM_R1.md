# Marketing System R1

状態: 仮説・運用計画。外部投稿、連絡、広告出稿は今回実施しない。内部fixtureを市場向けに宣伝しない。

## ゲームが入口
Short / creator / search → 特定ゲームの詳細 → 実プレイ → 関連する自社ゲーム → 再訪。

Portal全体の一般的な紹介より、最も伝わる作品1〜2本を入口にする。約10本を一律に宣伝しない。ゲーム名は覚えやすくし、権利・商標確認後に確定。日本語と英語をそれぞれ自然な言葉で用意する。Shortsの視聴回数をサイト訪問数と同一視しない。

## 1本のクリップの設計
すぐ分かる問題/障害 → プレイヤーの試み → 可視の成功・失敗・進化 → 自分ならどうするか。全解答や展開を見せ切るだけにならないよう、別の試し方や操作する快感を残す。視聴維持やクリック率への効果は未検証。意図をテストし、実測で判断する。

HUDが読みやすく、余計な通知/広告で見どころが隠れない録画を目指す。作者が実プレイを撮りやすい構成とし、将来必要なら音量/字幕/録画向け表示を作品ごとに設計する。今は録画モードやクリップ生成システムを追加しない。

## 観測
| 段階 | 使うイベント/検証 |
|---|---|
| 訪問 | 将来、明示的なキャンペーン導線の集計。個人追跡は目的を確認 |
| 読込 | game_load_start → success/error |
| 初操作 | first_input、ロードから操作までの離脱 |
| 理解・進行 | meaningful_progress / stage_complete / run_completeを作品固有に定義 |
| 回遊 | related_game_open → 次作品のload/input |
| 再訪 | 保存された進行からの復帰等。外部分析の定義・同意・保持は未確定 |

R1の最新50件メモリログは接続確認用で、実運用のfunnel集計や帰属分析はできない。架空のプレイヤー数/人気/星評価/収益/試遊感想は使用しない。

## クリエイター向け将来整備
作品別に録画/配信/収益化許可、音楽・効果音の権利、クレジット、ロゴ/サムネイル利用、禁止事項、ネタバレ取扱、連絡先を明文化する。今回の未確認素材を「配信自由」と告知しない。外部Portal向けは契約の独占と自己ホスト可否を確認してから進める。

## 支出判断
単位採算と継続が分からない段階で大きな有料広告費を使わない。まずHuman/小規模試遊の理解度と面白さを確認し、実測の入口→ロード→初操作→進行→回遊→再訪を改善する。目標値・予算・実績は現在unknown。
