Devices
Designed for desktop and mobile browsers.

Each game saves progress automatically in this browser on this device. Return to the same site in the same browser to continue from your saved progress. There is no Cloud Save.

Progress continuity is not guaranteed on another device or browser, after clearing site data, or in private browsing. Saves require the same address and port, with browser storage available.

How to play

Swipe a board to move both friends in the same direction. Use walls to stop one and bring both home together. Direction buttons, arrow keys and WASD also work.

Saves are shared across Japanese and English. Open the game menu for settings, hints and display layouts.
