プライバシー

Tinlumo Studio（個人運営）は、ゲームの提供とお問い合わせへの対応に必要な情報を、以下のとおり取り扱います。

アカウント登録、購入、広告、クラウド保存はありません。生年月日など年齢情報の入力も求めません。利用者を追跡する固有のIDや、端末の特徴を組み合わせた識別情報は作成しません。

端末内の保存

ゲームごとの進捗・クリア記録、動きを控える設定、消音・音量、Hakoriloの音楽設定、閉じた案内、選択した言語を、ブラウザのlocalStorageに保存します。続きから遊び、選んだ設定を保つために使います。自動的な有効期限はありません。

保存は同じ端末・ブラウザ・サイトでの利用を前提とします。別の端末やブラウザには引き継がれません。サイトデータの削除、プライベートブラウズ、保存領域の制限などにより、進捗や設定が失われる場合があります。

Hakorilo・ひかりの仕掛け庭・ふたりの帰り道の「この作品の進行を消去」は、その作品の進捗・クリア記録・動きを控える設定を消去します。音・案内・言語などの設定は残ります。すべて削除する場合は、ブラウザの設定からこのサイトのデータを削除してください。

表示や方向ボタンの設定、同じ利用開始を重複して記録しないための一時的な情報にはsessionStorageを使います。タブを復元すると残る場合があります。プレイ中の操作情報は端末のメモリに一時的に保持し、ページが破棄されると消えます。この操作情報を外部へ送信することはありません。

PROJECT MAGNETの保存

作戦の解放、記録、言語・消音・動きの設定、区画開始時点の再開データを、このブラウザに保存します。作戦画面のデータ消去では、PROJECT MAGNETの設定も含めてすべて消去します。他の作品の保存は変更しません。保存できない場合は画面に表示し、そのタブ内でのみ続行します。

サイトの配信

サイトの配信と保護にCloudflareを利用しています。Cloudflareは、これらの目的でIPアドレスやページの要求に伴う通信情報を処理する場合があります。

Cloudflareは世界各地で情報を処理・転送する場合があり、同社のプライバシーポリシーでは主な保管地域として米国と欧州経済領域（EEA）が示されています。保持期間は利用目的、必要性、法令上の義務などによって異なります。Tinlumoでは別途アクセスログを保管しませんが、Cloudflareによる処理・保持は行われる場合があります。

任意のアクセス計測

Cloudflare Web Analyticsによるアクセス計測は、初めて利用するブラウザでは無効です。計測を求める案内は自動表示しません。ページ下部の「計測の設定」から「計測を許可する」を選んだ場合に限り有効になります。選択しない場合も、計測を拒否した場合も、すべてのゲーム機能を利用できます。

以前このブラウザで保存した計測の許可・拒否は引き継がれます。選択はlocalStorageに保存し、訪問者IDは作成しません。自動的な有効期限はなく、「計測の設定」で変更できます。設定画面を開くことや、選択せずに閉じることは同意になりません。サイトデータを削除すると計測の選択だけでなく、ゲームの進行や設定も消える場合があります。

許可すると、ページURL、参照元、ブラウザ・端末情報、読み込み速度などの性能情報をCloudflareへ送信し、ページの利用状況と性能の改善に使います。Cloudflareは、利用状況の計測にCookieやlocalStorageを使わず、fingerprintingによる個人の識別をしないと説明しています。Tinlumoが選択を保存するlocalStorageと、Cloudflareの計測方式は別です。ゲーム内の操作や保存データをアクセス計測へ送信しません。

許可を取り消すとページを再読み込みして以後の計測を停止します。開始済みの通信は完了する場合があります。計測の通信失敗やブロックによってプレイを制限しません。Cloudflareでの取扱い・保持は同社のPrivacy Policy等によります。Tinlumoは一律の保持期間や即時削除を保証しません。サイト配信に必要な通信情報の処理は、任意のアクセス計測を無効にしても行われます。

この選択はCloudflare Web Analyticsだけを対象とし、広告への同意とは独立しています。現在、広告は配信していません。広告を導入する際は、必要な地域・処理に応じて説明と選択方法を別途案内します。

お問い合わせの情報

お問い合わせでお送りいただくメールアドレス・本文・添付ファイルなどと返信履歴は、内容の確認、必要な返信、法令に基づく請求への対応に使用します。Tinlumoが広告やAIの学習に利用することはありません。

メールの受信にはCloudflare Email Routingを、保管と返信にはGoogleのGmailを利用します。返信が別のメールアドレスから届く場合があります。

お問い合わせの本文は、対応終了後90日を目安に削除します。未解決のお問い合わせは月1回確認します。法令への対応、セキュリティ上の問題、不正利用、紛争などのために合理的な保持が必要な場合は、この限りではありません。メール事業者のごみ箱やバックアップには別途残る場合があり、直ちにすべて削除されることは保証できません。

Gmailで削除したメールはごみ箱に移り、通常30日後に完全削除されます。Googleの一般的な削除処理には通常約2か月かかり、暗号化バックアップには最長6か月残る場合があります。法令などによる例外や遅延があり、個々のメールの削除完了日時は保証できません。Googleは世界各地のサーバーを使用し、お住まいの国以外で情報を処理する場合があります。
