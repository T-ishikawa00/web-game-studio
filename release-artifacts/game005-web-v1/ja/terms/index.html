利用規約

サービスの利用

Tinlumoは、日本語と英語で遊べる5つの無料ブラウザゲームを提供します。 アカウント登録、購入、有料アイテム、広告、クラウド保存はありません。

保存とサービスの提供

進捗はお使いの端末のブラウザに自動保存されます。同じサイト・端末・ブラウザでの利用を前提とし、他の端末やブラウザには引き継がれません。設定変更、ブラウザの更新、容量不足、サイトデータの削除などで保存が失われる場合があります。サービスの継続・可用性や、保存データの保持・復元は保証できません。サービスの内容を変更したり、提供を停止したりする場合があります。これらの条件は、適用される法令によって制限できない利用者の権利を制限するものではありません。

島づくりゲームの保存

建物・資源・進行・配置と、言語・音・動き・画質の設定を、このブラウザに自動保存します。島の進行を消去しても設定は残ります。保存できない場合は画面にお知らせします。日本語と英語で進行を共有し、保存した言語設定を優先します。

PROJECT MAGNETの保存

作戦の解放、記録、言語・消音・動きの設定、区画開始時点の再開データを、このブラウザに保存します。作戦画面のデータ消去では、PROJECT MAGNETの設定も含めてすべて消去します。他の作品の保存は変更しません。保存できない場合は画面に表示し、そのタブ内でのみ続行します。

権利と利用上のお願い

Tinlumoのゲーム、パズル、画像、音声と、使用するオープンソースソフトウェアには、それぞれ適用される権利とライセンスがあります。詳しくはクレジットと同梱のライセンス表示をご覧ください。通常のプレイ、本サイトの動画利用方針、適用法令または個別のライセンスで認められる場合を除き、ゲームや素材の無断複製・再配布を禁止します。不正アクセス、なりすまし、サービスの妨害、他者の権利を侵害する利用も禁止します。個別のオープンソースライセンスによる許諾は制限しません。
