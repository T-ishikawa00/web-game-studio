# Game009 controls and accessibility

The one-pointer layout supports sequential stoking and vent adjustment; simultaneous multi-touch is not required. Hold STOKE to sustain feeding; release stops feeding but leaves ember heat. Moving VENT changes 0–100% airflow. FINISH is visibly locked until the final phase meets its public timing, temperature and quality conditions. The pitcher adds active controlled cooling before finishing.

Keyboard: hold Space or Enter to stoke, ordinary taps add a small pulse, left/right arrows change vent by seven percentage points, F finishes, Escape pauses. Pointer cancellation, lost capture, blur, visibility loss and pause clear active inputs. Browser/OS shortcuts with Ctrl/Meta/Alt are preserved. Start, pause, language and settings use native focusable HTML controls. STOKE, VENT and FINISH are drawn inside the interactive canvas, with equivalent keyboard commands and descriptive public status/instructions. This game requires visual temperature reading and is not a complete nonvisual play experience.

JA/EN language switching updates the shell, canvas labels, live HUD, result and controls. Settings: sound mute, volume, reduced motion and high contrast. No music is included. Reduced motion removes shimmer/pulsing decoration while retaining necessary state changes. High contrast affects both the canvas and shell. Current/next target ranges and numeric status accompany color cues. Control boxes are 110 logical pixels high on a 720 logical square, about 51 CSS pixels at a 333 CSS-pixel board.

Actual physical touch devices and iOS Safari remain NOT TESTED until evidence is recorded. A phone-size desktop browser with ordinary pointer input establishes responsive geometry and sequential control reachability, not physical touchscreen compatibility.
