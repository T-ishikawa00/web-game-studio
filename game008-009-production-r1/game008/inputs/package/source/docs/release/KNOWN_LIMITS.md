# COILHOP standalone r1 known limitations

Standalone production scope is complete and internally reviewed. Portal integration/Production publication are BLOCKED, recorded in release/PORTAL_HOLD.md. Local completeness does not imply a public release or Human acceptance.

- Browser play is AI-agent controlled ordinary pointer/keyboard input using authored charge guides. All eight courses reached the summit; both alternatives of both forks were completed and read back as 2/2. This is not an independent first-time-player study. The 5–15 minute target remains a product hypothesis. The full-campaign exercise records 469,050 ms, excluding 45,209 ms of initial integration regression: 423,841 ms valid aggregate. It includes a partial repeated course and deliberate failure, not an uninterrupted fresh-player duration.
- Each slice comparison exceeds 15 valid controlled minutes. Counters include deliberate faults and different input units, and do not establish comparative completion rates, retention, demand, traffic or revenue.
- Physical smartphone touch, iOS/Safari, Android hardware, low-end performance and a full browser matrix are NOT TESTED. Phone-width play uses 375×700 pointer-emulated Chromium. Marketing footage is not physical-device footage.
- Audio is original Web Audio synthesis. All three MP4s have nonzero decoded audio below clipping. Human listening quality and device-speaker compatibility are NOT VERIFIED; no BGM/narration is supplied.
- Keyboard, visible focus, localized labels/live messages, modal focus wrapping, pause and reduced effects are implemented. Browser Space/Escape and source lifecycle checks passed. Screen-reader use, exhaustive zoom/contrast and assistive-device acceptance are NOT TESTED. Essential platform/camera movement remains with reduced effects.
- Saves are origin-local. Full-game progress is separate from slice/other-game namespaces. Site-data deletion removes local progress. Quota/denial/corrupt/unknown-schema behavior is source-tested; browser completion/settings/readback and game-only cross-tab reset passed. All storage/browser permutations are not tested.
- Replay varies moving-platform phase, tracks two binary forks and best medals. There are eight finite courses, without an endless generated mode.
- Capture UI is disabled on nonloopback hosts and absent by default. The local capture POST endpoint exists only in the normal-source developer server, not the static package or its server mode.
- Covers/clips precede final screen-reader language-announcement/map/reset-target corrections. Gameplay geometry, motion and sounds shown match the final game. Raw captures and input logs are retained. Final package bytes/manifest are separately verified.
- No analytics, account, cloud save, ads, remote font or third-party runtime dependency ships. Portal Consent/measurement/new play AdSense exclusion/old-six-game regression/Production readback remain unperformed integration work.
- Six requested Luna reviews are internal source/screenshot assessments. Runtime model identity was not independently exposed: UNKNOWN. Internal PASS covers documented source, visual, ordinary-input and package checks, not Human craft acceptance or market viability.
