==================================================
1. CORE RULE
==================================================

現行60秒モードを削除しない。

60秒モードは：

QUICK RUN

として維持する。

Complete Editionでは、
Quick Runとは別に
「最後まで遊べる主モード」を追加する。

Humanの追加好み確認なしで、
Codexが調査・実プレイ・比較から最適な構成を選んでよい。

候補例：

- multi-stage run
- campaign
- progressive arcade run
- survival with finale
- challenge ladder
- escalating arenas
- boss / finale structure
- endless after clear

ただし、
既存のCore Loopと無関係なMeta Gameを大量追加しない。

==================================================
2. TARGET SESSION
==================================================

主モードは：

平均5〜12分程度で
「始まり → 上達 → 山場 → 最後 → Result」
を感じられる構造を目標とする。

固定時間にする必要はない。

最終的にHumanが
「60秒のミニゲーム」ではなく
「一本の完成ゲーム」と感じられることを目的とする。

Quick Runは現在の高速体験を維持。

==================================================
3. RESEARCH
==================================================

実装前に、
「短いArcade CoreをどうFull Gameへ拡張しているか」
を中心に調査する。

対象：

- browser arcade
- score attack
- physics action
- arena survival
- chain / combo games
- Peggle-like trajectory games
- short-session mobile action
- roguelite-lite
- stage progression arcade

20〜40作品程度を比較。

見るもの：

- session length
- progression
- difficulty curve
- content density
- failure / retry
- finale
- score motivation
- run variation
- tutorial burden
- mobile controls
- replay reason

単なるジャンル名ではなく、
RIMBLOOMへ移植可能な構造を抽出。

既存作品のVisualやThemeをコピーしない。

この三層を目標。
